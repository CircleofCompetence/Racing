# MINI Racer

빨간 미니 스포츠카로 거대한 거실의 장난감 장애물을 피하는 모바일 3D 레이싱 게임입니다. 낮은 미니카 시점에서 여러 모양의 블록, 공, 컵, 책, 연필, 오리, 로봇, 장난감 기차, 북, 링 쌓기, 곰 인형과 거대한 가구 사이를 달립니다.

## 게임 방법

- 화면 아래 `LEFT`와 `RIGHT`를 누르고 있는 동안 좌우로 움직입니다.
- `JUMP`를 누르면 미니카가 살짝 뛰어 책과 연필 같은 작은 장애물을 넘습니다.
- 상단 `VIEW` 버튼을 누르면 미니카 외부 시점과 운전석 내부 시점을 전환합니다.
- 안전 통로에 나타나는 번개 모양 부스터를 먹으면 5초간 속도가 크게 올라갑니다.
- 시간이 지날수록 기본 속도와 장애물 수가 증가합니다.
- 다섯 개의 주행 라인을 기준으로 장애물이 생성되며, 항상 피할 수 있는 넓은 안전 통로가 남습니다.
- 충돌 한 번에 에너지 10이 줄고, 10번 충돌하면 레이스가 끝납니다.
- PC에서는 방향키 또는 A/D, 스페이스바로도 플레이할 수 있습니다.

## GitHub Pages에 올리기

1. 숨김 폴더인 `.github`와 `public/vendor`를 포함해 이 폴더 전체를 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**에서 **GitHub Actions**를 선택합니다.
4. 저장소의 **Actions** 탭에서 `Deploy MINI Racer to GitHub Pages` 작업이 완료될 때까지 기다립니다.
5. 작업에 표시되는 웹 주소를 휴대폰에서 열면 바로 게임할 수 있습니다.

3D 라이브러리 파일이 업로드에서 빠진 경우에도 CDN에서 자동으로 다시 불러옵니다.

외부 음원이나 3D 모델 없이 실행되며 Three.js 라이브러리도 프로젝트에 포함되어 있습니다. 브라우저 정책상 사운드는 `ENGINE START` 버튼을 누른 뒤 시작됩니다.
